下载 **block-world-cn-v0.1.0-windows-x64-offline.zip**，完整解压后双击 **一键启动.cmd**。首次从内置 ZIP 部署，后续直接启动；游玩无需账号或联网。SHA256SUMS.txt 提供完整包校验值。

已验证核心采集/GUI 合成/建造/保存重载；熔炼使用专门提供的测试材料。村民、完整作物周期、复杂红石、维度通关未全部实测。当前不是统一原版版本的完整复刻，不含真实树木/地形水面倒影、SSAO 或写实云。
