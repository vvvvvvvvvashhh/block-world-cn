# 真实缺项清单

本次交付是可玩的 Luanti 5.17.0 + Mineclonia 0.123.1 中文离线版。下面分别标明实际差异与未验证范围，不能把上游存在某个模块等同于该模块全部玩法已通过本机验收。

## 已知与请求不一致

- **版本一致性**：以 Java 1.21 的菜单、背包和 HUD 布局作参考，玩法仍由 Mineclonia 0.123.1 定义；尚未逐条对齐同一个 Minecraft 正式版本的配方、数值、战斗、生成和红石行为。
- **界面**：已实现真实中文单人菜单、选项、世界创建、2×2/3×3 合成、九格快捷栏、血量、饥饿与经验条。字体、图标、皮肤、配方书、鼠标转移细节、暂停和高级设置仍保留开源底座差异。没有原版旋转全景菜单，也没有逐像素 UI 复刻。部分物品和高级页面翻译可能不完整。
- **美术**：使用 Pixel Perfection/Legacy 等开源像素材质及自制几何 HUD，不包含 Mojang 原版素材；与附图的植被颜色、方块纹理和角色手臂不同。
- **水面**：已有动态波纹、天空/光源反射与菲涅耳效果；缺少真正反射岸边树木与地形的 SSR/平面反射，不能复现附图中的完整倒影。
- **光照**：已有柔和动态阴影、节点级 AO、雾、色调映射、泛光和体积光。没有 SSAO、路径追踪、完整 PBR 光照或附图中的写实云层。阴影距离和透明材质效果受引擎限制。
- **世界管理**：可新建、选择、进入世界和打开存档目录；没有实现原版的完整编辑、导入、删除、资源包管理流程。菜单没有为这些缺项放置空按钮。
- **存档兼容**：使用 Luanti/Mineclonia 的 SQLite 世界，不兼容 Minecraft Anvil 存档、Java 模组、数据包或光影包。

## 已继承，尚未完整验收的玩法

| 系统 | 已有底座 | 本次未验证的范围 |
|---|---|---|
| 分块世界、生物群系 | 分块生成、加载与落盘；自然地形 | 所有群系/结构组合、极远距离边界 |
| 昼夜、天气 | 上游昼夜、降雨/雷暴等模块 | 完整多日循环与所有天气交互 |
| 装备、战斗、生物 AI | 工具、武器、盔甲、友好/敌对生物 | 全装备数值、全部生物行为与长期战斗 |
| 种植 | 作物、耕地与生长模块 | 从播种到收获的全作物周期与复杂自动农场 |
| 村庄 | 村庄生成、村民等模块 | 各村庄类型、交易与村民 AI 的完整实机流程 |
| 红石 | 导线、开关、活塞、观察者等 | 大规模电路、时序/准连接等与 Java 的逐条一致性 |
| 下界、末地 | 维度及传送相关模块 | 建门、探索、终局战斗、返回主世界的完整通关链 |
| 创造 | 创造库存、飞行、快速建造 | 全物品索引与所有创造交互的回归 |

核心生存材料闭环已验证到原木、木板、工作台与建筑；熔炼使用隔离测试提供的原铁和煤。没有把后者冒充为“从零挖铁到炼铁”的全程生存实测。种植、村庄、红石高级装置和维度不能标为本次已通关验收。

## 性能与稳定性边界

- 默认设置下观测约 59 FPS；没有最低帧率、1% low、长时间压力或不同显卡基准。
- 地图生成、复杂电路、大量生物、远距离和高画质仍可能产生卡顿。
- 已检查数据库完整性、备份 CRC、退出重载和离线恢复；没有执行突然断电、磁盘故障或长时间耐久测试。
- 引擎在本机产生 builtin 文件 SHA256 未识别提示，来自原始 Windows 发行包的路径/校验记录，未关闭安全机制。原始日志保留，不能据此声称完全无警告。

后续优先项应是统一目标版本的行为差异表、森林水岸光影、完整食物/工具进阶实测，再逐步扩展农场、村民、复杂红石与维度通关回归。
